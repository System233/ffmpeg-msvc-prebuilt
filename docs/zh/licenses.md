# 许可证与再分发

## 选择许可证

选择许可证时，应依据实际启用组件和使用、链接、分发方式，而不是仅依据下载标签。

| 构建 | 说明 |
|---|---|
| GPL | 可包含 x264、x265 等 GPL 组件；遵守适用 GPL 条款。 |
| LGPL | 新版构建流程限制不兼容组件；历史构建存在已披露的风险。 |
| Nonfree | 不属于可再分发的构建模式。 |

使用 `ffmpeg -buildconf` 查看配置，使用 `ffmpeg -encoders` 查看实际编码器。配置和功能列表不能单独证明许可证合规。

## 历史 LGPL 构建

部分历史 LGPL 构建存在 GPL 组件或其他许可证兼容性问题。不要将带有风险提示的归档视为已经确认合规的 LGPL 构建。详见[更新历史中的许可证说明](../history/#历史-lgpl-构建)，其中列出已确认的证据、修复和未决事项。修复适用于新构建，历史归档仍需独立核验。

## 再分发检查

在应用中嵌入 FFmpeg，或将 FFmpeg 二进制文件与应用一起分发时：

1. 核查实际使用的构建、组件及其适用许可证。
2. 保留必要的许可证文本、版权声明和其他归属信息。
3. 按适用许可证满足对应源代码提供义务，包括相关修改和构建材料。
4. 核查应用与 FFmpeg 的链接及分发方式；适用 LGPL 时，还应满足用户替换库或重新链接等相关要求。
5. 对第三方组件的独立许可要求另行核查。

仅使用共享库 DLL 或附带 SPDX 文件，并不自动满足上述义务。应按实际分发方式和适用许可证全文评估。

## 归档中的许可证文件

新版构建产物包含：

| 文件 | 用途 |
|---|---|
| `LICENSE.txt` | 主许可证 |
| `share/ffmpeg/copyright` | 合并的版权声明 |
| `share/ffmpeg/sbom.spdx.json` | SPDX 2.3 依赖信息 |

新版发布流程增加了显式许可证兼容性检查和归档证据验证。SBOM 记录安装的依赖图，不单独证明最终链接对象，也不替代对应源代码或其他许可证义务。原始依赖证据及构建溯源保留于归档之外。

如需定制组件，请参考[功能参考](../reference/)及[自行构建](../self-build/)。
